# 剧情点功能

## 概述

- 玩家每经过一个剧情点（用场景中的石像代替）就会触发剧情点，获得长老问题的答案

- 触发所有剧情点后才能与长老（用NPC2代替）对话并回答问题

## 使用方法

- 添加剧情点与添加对话的方法大体一致，需要一个正方体作为碰撞箱
- 在`PlotProgressManager`里可以添加所有必须要触发的剧情点（填每个剧情点挂载的`TextShowTrigger.cs`的`PlotPointID`）
- 如果需要触发所有剧情点才能与之对话，勾选`DialogueTrigger.cs`的“Require All Plot Points”

# 图鉴功能

## 概述

- 添加了Book组件用于实现图鉴像“书”一样的翻动效果
- 按"E"打开图鉴，按ALT唤出鼠标可以翻动图鉴
- 图鉴初始默认所有页都“未知”，每触发一个剧情点可以解锁一页

## 使用方法

- 修改每个剧情点挂载的`TextShowTrigger.cs`的`Image`可以修改图鉴更新后的页面
- 在`BookPro`的`Papers`下可以增加或者减少图鉴页面数量
