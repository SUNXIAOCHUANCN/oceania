## 现有的删除存档的方法

### GlobalSaveManager.DeleteAllSaveData()

**文件位置**：`GlobalSaveManager.cs:327-361`

**当前实现**：

```csharp
public void DeleteAllSaveData()
{
    Debug.Log("[GlobalSaveManager] 删除所有存档...");

    // 1. 尝试调用 PlayerStateManager 的方法（如果存在）
    if (playerStateManager != null)
        playerStateManager.DeleteSaveFile();

    // 2. 手动删除其他系统的存档文件
    string forestSavePath = Path.Combine(Application.persistentDataPath, "forest_save.dat");
    string farmSavePath = Path.Combine(Application.persistentDataPath, "farm_save.dat");
    string ranchSavePath = Path.Combine(Application.persistentDataPath, "ranch_save.dat");
    string exploreSavePath = Path.Combine(Application.persistentDataPath, "explore_save.dat");
    string populationSavePath = Path.Combine(Application.persistentDataPath, "population_save.dat");

    if (File.Exists(forestSavePath))
        File.Delete(forestSavePath);

    if (File.Exists(farmSavePath))
        File.Delete(farmSavePath);

    if (File.Exists(ranchSavePath))
        File.Delete(ranchSavePath);

    if (File.Exists(exploreSavePath))
        File.Delete(exploreSavePath);

    if (File.Exists(populationSavePath))
        File.Delete(populationSavePath);

    // 3. 删除 PlayerPrefs 的时间存档
    PlayerPrefs.DeleteKey("GlobalTimeSystem_TotalElapsedTime");
    PlayerPrefs.DeleteKey("GlobalTimeSystem_FirstStart");

    Debug.Log("[GlobalSaveManager] 所有存档已删除");
}
```

## 计划实现"开始新游戏"的方案概述

### 设计目标

1. ✅ 在开始场景中提供"新游戏"按钮
2. ✅ 清空所有存档数据
3. ✅ 加载游戏主场景并使用初始状态

```
场景流程：
┌─────────────────┐
│  StartScene     │  ← GlobalSaveManager在这里
│  (开始场景)      │     DontDestroyOnLoad
```

### 步骤1：修改 GlobalSaveManager - 让其不依赖实例

**文件**：`Assets/System/SaveLoad/GlobalSaveManager.cs`

#### 1.1 修改 HasAnySaveData() 方法

```csharp
/// <summary>
/// 检查是否存在任何存档（不依赖SaveSystem实例）
/// </summary>
public bool HasAnySaveData()
{
    string basePath = Application.persistentDataPath;

    // 直接检查文件是否存在
    bool hasPlayerSave = File.Exists(Path.Combine(basePath, "player_state.dat"));
    bool hasFarmSave = File.Exists(Path.Combine(basePath, "farm_save.dat"));
    bool hasForestSave = File.Exists(Path.Combine(basePath, "forest_save.dat"));
    bool hasRanchSave = File.Exists(Path.Combine(basePath, "ranch_save.dat"));
    bool hasExploreSave = File.Exists(Path.Combine(basePath, "explore_save.dat"));
    bool hasPopulationSave = File.Exists(Path.Combine(basePath, "population_save.dat"));
    bool hasTimeSave = PlayerPrefs.HasKey("GlobalTimeSystem_TotalElapsedTime");

    return hasPlayerSave || hasFarmSave || hasForestSave ||
           hasRanchSave || hasExploreSave || hasPopulationSave || hasTimeSave;
}
```

**修改原因**：
- ✅ 原方法依赖 SaveSystem 实例（在开始场景为 `null`）
- ✅ 新方法直接检查文件，可在任何场景调用

#### 1.2 修改 DeleteAllSaveData() 方法

```csharp
/// <summary>
/// 删除所有存档（不依赖SaveSystem实例）
/// </summary>
public void DeleteAllSaveData()
{
    Debug.Log("[GlobalSaveManager] 删除所有存档...");

    string basePath = Application.persistentDataPath;

    // 直接删除文件，不依赖实例
    DeleteSaveFileIfExists(basePath, "player_state.dat");
    DeleteSaveFileIfExists(basePath, "farm_save.dat");
    DeleteSaveFileIfExists(basePath, "forest_save.dat");
    DeleteSaveFileIfExists(basePath, "ranch_save.dat");
    DeleteSaveFileIfExists(basePath, "explore_save.dat");
    DeleteSaveFileIfExists(basePath, "population_save.dat");

    // 删除 PlayerPrefs 的时间存档
    PlayerPrefs.DeleteKey("GlobalTimeSystem_TotalElapsedTime");
    PlayerPrefs.DeleteKey("GlobalTimeSystem_FirstStart");

    Debug.Log("[GlobalSaveManager] 所有存档已删除");
}

/// <summary>
/// 辅助方法：删除文件（如果存在）
/// </summary>
private void DeleteSaveFileIfExists(string basePath, string fileName)
{
    string fullPath = Path.Combine(basePath, fileName);
    if (File.Exists(fullPath))
    {
        File.Delete(fullPath);
        Debug.Log($"[GlobalSaveManager] 已删除: {fileName}");
    }
}
```

**修改原因**：
- ✅ 统一删除方式，不再部分依赖实例、部分手动删除
- ✅ 添加辅助方法，减少重复代码
- ✅ 添加日志，便于调试

### 步骤2：创建开始场景的 UI 管理器

**新建文件**：`Assets/System/SaveLoad/MainMenuController.cs`

```csharp
using UnityEngine;
using UnityEngine.SceneManagement;

/// <summary>
/// 主菜单控制器 - 管理开始场景的UI交互
/// </summary>
public class MainMenuController : MonoBehaviour
{
    [Header("UI按钮")]
    [SerializeField] private GameObject newGameButton;
    [SerializeField] private GameObject continueGameButton;
    [SerializeField] private GameObject quitButton;

    void Start()
    {
        // 检查是否有存档，启用/禁用"继续游戏"按钮
        bool hasSave = GlobalSaveManager.Instance.HasAnySaveData();
        if (continueGameButton != null)
        {
            continueGameButton.SetActive(hasSave);
        }

        Debug.Log($"[MainMenuController] 检测到存档: {hasSave}");
    }

    /// <summary>
    /// 新游戏按钮点击事件
    /// </summary>
    public void OnNewGameClicked()
    {
        Debug.Log("[MainMenuController] 点击新游戏");

        // 删除所有存档
        if (GlobalSaveManager.Instance != null)
        {
            GlobalSaveManager.Instance.DeleteAllSaveData();
            Debug.Log("[MainMenuController] 所有存档已删除");

            // 加载游戏场景
            SceneManager.LoadScene("GameScene");
        }
        else
        {
            Debug.LogError("[MainMenuController] GlobalSaveManager.Instance 为 null！");
        }
    }

    /// <summary>
    /// 继续游戏按钮点击事件
    /// </summary>
    public void OnContinueGameClicked()
    {
        Debug.Log("[MainMenuController] 点击继续游戏");

        // 直接加载游戏场景（GlobalSaveManager会自动加载存档）
        SceneManager.LoadScene("GameScene");
    }

    /// <summary>
    /// 退出游戏按钮点击事件
    /// </summary>
    public void OnQuitClicked()
    {
        Debug.Log("[MainMenuController] 点击退出游戏");

        #if UNITY_EDITOR
            UnityEditor.EditorApplication.isPlaying = false;
        #else
            Application.Quit();
        #endif
    }
}
```

## 用户提出的问题

### 问题1：作物 ScriptableObject 数值修改与存档的冲突

**问题**：
> 如果要设置作物 ScriptableObject 的数值，修改哪些数值？如何保证修改的数值与存档不冲突？

**答案**：

#### 可修改的数值

**基本信息**：
- `speciesName` - 物种名称
- `speciesType` - 物种类型
- `speciesDescription` - 描述
- `icon` - 图标
- `source` - 来源
- `state` - 野化状态
- `unlocked` - 是否解锁

**产量属性**：
- `initialYield` - 初始产量
- `growthPhases` - 生长阶段数
- `decayPerPhase` - 每个阶段衰退的产量
- `leastYield` - 最低产量

**消耗属性**：
- `initialCropConsumption` - 初始消耗谷物
- `monthlyCropConsumption` - 每个月相消耗谷物

#### 存档系统保存的内容

存档只保存**运行时数据**：
- `cropSpeciesName` - 作物名称
- `currentNPY` - 当前运行时产量
- `growthPhaseCount` - 生长阶段计数

#### 不会冲突的原因

| 数据类型 | 存储位置 | 会被修改吗 | 是否存档 |
|---------|---------|-----------|---------|
| **SpeciesScriptableObject 配置** | 项目资源文件 | ❌ 不在运行时修改 | ❌ 不存档（永久配置） |
| **运行时数据** | FieldUnit 实例 | ✅ 每个月相变化 | ✅ 存档保存 |

#### 实际影响示例

```
场景：修改 "小麦" 的 initialYield 从 100 → 150

情况A：存档中有田地种着 "小麦"，currentNPY = 80
→ 加载后继续使用 80（不受配置影响）

情况B：玩家重新种植 "小麦"
→ 使用新的 initialYield = 150
```

#### 注意事项

- ✅ 修改 ScriptableObject 配置是安全的
- ✅ 只影响新种植的作物
- ⚠️ 不要修改已有的 `speciesName`（存档通过名称查找作物）

### 问题3：开始场景和游戏主场景分离的架构问题

**问题**：
> 假设有2个场景，一个场景是开始页面，一个场景是游戏主页面，显然所有的SaveSystem都在第二个场景里面。那么我应该如何编写清空所有存档实现新游戏的脚本？

**答案**：

#### 问题分析

**当前架构的问题**：
```csharp
// GlobalSaveManager.cs:310-322
public bool HasAnySaveData()
{
    bool hasSave =
        (playerStateManager != null && playerStateManager.SaveExists()) ||  // ❌ 在开始场景为null
        (forestSaveSystem != null && forestSaveSystem.SaveExists()) ||      // ❌ 在开始场景为null
        // ...
}
```

在开始场景中，所有 SaveSystem 引用都是 `null`，导致：
- ❌ `HasAnySaveData()` 返回 `false`（即使有存档）
- ❌ "继续游戏"按钮错误地显示为不可用

#### 解决方案

**核心原则**：让存档管理**不依赖 SaveSystem 实例**

**实现方式**：
1. `HasAnySaveData()` 直接检查文件存在性
2. `DeleteAllSaveData()` 直接删除文件
3. 使用 `File.Exists()` 和 `File.Delete()` 而不是调用实例方法

#### 完整流程

```
玩家启动游戏
    ↓
StartScene 加载
    ↓
GlobalSaveManager.Awake()
    → DontDestroyOnLoad ✅
    ↓
GlobalSaveManager.FindSystemReferences()
    → 找不到 SaveSystem（因为它们在GameScene）
    → 所有引用都是 null ✅（这是正常的）
    ↓
MainMenuController.Start()
    → HasAnySaveData() 检查文件 ✅（不依赖实例）
    → 如果有存档，显示"继续游戏"按钮
    ↓
玩家点击"新游戏"
    → DeleteAllSaveData() 删除文件 ✅（不依赖实例）
    → LoadScene("GameScene")
    ↓
GameScene 加载
    ↓
各个 SaveSystem.Awake() 创建实例 ✅
    ↓
GlobalSaveManager.FindSystemReferences()
    → 找到所有 SaveSystem ✅
    ↓
GlobalSaveManager.AutoLoadOnStart()
    → HasAnySaveData() → false（刚才删除了）
    → 使用初始状态 ✅
```

#### 场景配置

**StartScene（开始场景）**：
```

│   └── MainMenuController.cs
```
