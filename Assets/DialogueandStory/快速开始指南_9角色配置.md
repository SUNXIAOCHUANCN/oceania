## 🚀 5分钟快速配置

### 第1步：准备角色头像（2分钟）

1. **打开工具窗口**
   ```
   Unity菜单: Tools → 对话系统 → 角色头像映射生成器
   ```

2. **创建文件夹**
   - 点击 **"创建推荐的文件夹结构"** 按钮
   - 会自动创建：
     - `Assets/Resources/CharacterSprites/`
     - `Assets/DialogueandStory/CharacterMappings/`

3. **放入头像图片**
   - 将9个角色的头像文件放入 `CharacterSprites` 文件夹
   - 确保每个图片的 **Texture Type** 设置为 **Sprite (2D and UI)**

### 第2步：生成全局映射配置（1分钟）

1. **在工具窗口中点击** **"扫描头像文件"**
   - 应该显示找到9个文件

2. **点击** **"生成角色映射配置"**
   - 自动创建 `GlobalCharacterMapping.asset`
   - 包含所有9个角色的映射关系

### 第3步：创建NPC并导入台词（2分钟）

#### 示例：创建"与孩子们对话"的NPC

1. **创建NPC对象**
   ```
   Hierarchy → 右键 → Create Empty
   命名为: NPC_VillageChildren
   ```

2. **添加组件**
   - Add Component → Box Collider
     - Is Trigger: ✓ 勾选
     - Size: (2, 2, 2)
   - Add Component → Dialogue Trigger

3. **配置Dialogue Trigger**
   - **Character Mapping**: 拖入 `GlobalCharacterMapping`
   - **NPC Transform**: 拖入 `NPC_VillageChildren` 自己
   - **Plot Point ID**: `met_children` (可选)

4. **导入台词**
   - 点击 **"浏览文件"** 选择 `2长尾鸟岛村落旁与孩子们对话.txt`
   - 点击 **"导入台词"**

✅ 完成！测试游戏，走近NPC触发对话。

## 🎨 台词文件格式

### 标准格式

```
[角色名]：对话内容

[基诺]：在争论什么呢？
[拉拉]：我们在比赛唱"岛谣"！
[库拉奶奶]：让我来听听...
```

### 完整示例

**文件：2长尾鸟岛村落旁与孩子们对话.txt**

```
[基诺]：（走近，带着笑意）
[基诺]：在争论什么呢？
[拉拉]：（跳下石头，眼睛亮晶晶地）
[拉拉]：基诺姐姐！我们在比赛唱"岛谣"，但他们总唱错！
[基诺]：那让我也听听看，是不是这样——"弯弯的月儿，躺在海中央……"
[孩子们]：（齐声接上，手拉手轻轻摇晃）
[孩子们]：一头枕着珊瑚床，一头翘着看远方！
[拉拉]：（兴奋地比划着弧线）
[拉拉]：长长的尾巴尖，指向星辰落下的地方……
```

**系统会自动：**
- ✅ 解析 `[角色名]：内容` 格式
- ✅ 切换到对应角色的头像
- ✅ 最后一行自动标记为对话结束

## 🔄 创建多个NPC的流程

假设你要创建5个NPC：

### NPC 1: 孩子们
```
NPC_Children
├─ Character Mapping: GlobalCharacterMapping (所有NPC共用)
├─ 台词文件: 2长尾鸟岛村落旁与孩子们对话.txt
└─ 涉及角色: [基诺][拉拉][孩子们]
```

### NPC 2: 库拉奶奶
```
NPC_KulaGrandma
├─ Character Mapping: GlobalCharacterMapping (同一个配置)
├─ 台词文件: 3与库拉奶奶对话.txt
└─ 涉及角色: [库拉奶奶][基诺]
```

### NPC 3: 玛莱
```
NPC_Malai
├─ Character Mapping: GlobalCharacterMapping (同一个配置)
├─ 台词文件: 4与玛莱对话.txt
└─ 涉及角色: [玛莱][基诺][拉拉]
```

### ... 以此类推

**所有NPC都使用同一个 `GlobalCharacterMapping`**，这样：
- ✅ 统一管理所有角色头像
- ✅ 任何NPC都可以让任何角色说话
- ✅ 添加新角色时只需更新一个配置文件

## ⚙️ 工具使用说明

### 角色头像映射生成器

**位置：** `Tools → 对话系统 → 角色头像映射生成器`

**功能：**
1. 📁 自动扫描文件夹中的所有Sprite
2. 🏷️ 从文件名自动提取角色名
3. 📦 一键生成CharacterSpriteMapping配置

**使用步骤：**
```
1. 将角色头像放入一个文件夹
2. 在工具中选择该文件夹
3. 点击"扫描头像文件"
4. 预览提取的角色名
5. 点击"生成角色映射配置"
```

## 🎯 角色名匹配规则

txt文件中的角色名必须与配置中的名字**完全一致**：

| txt文件中的名字 | ✅ 正确 | ❌ 错误 |
|----------------|--------|--------|
| `[基诺]` | 基诺 | 基诺 、 基诺、基诺 |
| `[库拉奶奶]` | 库拉奶奶 | 库拉、奶奶 |
| `[孩子们]` | 孩子们 | 孩子 |

**提示：** 如果文件名包含下划线，系统会自动提取第一部分作为角色名
- `基诺_Happy.png` → 提取为 `基诺`
- `Lala_Smile.png` → 提取为 `Lala`

## 🐛 常见问题解决

### 问题1：头像不显示或切换
**原因：** 角色名不匹配
**解决：** 检查txt文件中的角色名与GlobalCharacterMapping中的名字是否完全一致

### 问题2：找不到GlobalCharacterMapping
**原因：** 配置文件未创建或路径错误
**解决：** 使用角色头像映射生成器工具重新创建

### 问题3：导入台词失败
**原因：** txt文件格式错误
**解决：** 确保每行格式为 `[角色名]：对话内容`

## 💡 进阶功能

### 分支对话示例

手动配置时，可以设置玩家选择：

```
Element 0:
├─ text: "你想要什么帮助？"
├─ isQuestion: ☑
├─ answerOption1: "我想了解岛屿的历史"
├─ answerOption2: "我想接受任务"
├─ option1IndexJump: 1  → 跳转到历史分支
└─ option2IndexJump: 5  → 跳转到任务分支
```

### 剧情进度控制

在DialogueTrigger中设置前置条件：

```
Required Plot Points: ["tutorial_completed", "met_kula"]
```

这样玩家必须先完成这些剧情点才能触发对话。
