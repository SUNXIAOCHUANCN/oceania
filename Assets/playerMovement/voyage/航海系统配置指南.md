# 航海系统Unity配置指南

## 📋 概述

航海系统已实现以下功能：
- ✅ 玩家在SpawnPoint可以上船
- ✅ 选择不同船只消耗不同资源（Crop/Ani/Mat）
- ✅ 在岛屿范围内可以下船（按钮+F键）
- ✅ 下船后船只销毁
- ✅ 玩家在船上退出游戏，下次重生到安全点

---

## 🎯 Unity配置步骤

### 步骤1：创建VoyageSystemManager对象

1. **创建空对象**
   - Hierarchy → Create Empty
   - 重命名为 "VoyageSystemManager"

2. **添加组件**
   - Add Component → 搜索 `VoyageSystemManager`
   - 或者直接拖拽脚本到对象上

3. **配置资源消耗**
   - 在Inspector中展开 **Ship Costs** 数组
   - 设置 **Size** 为 3
   - 配置3种船的资源消耗：

| 元素 | Ship Type | Crop Cost | Ani Cost | Mat Cost | 说明 |
|------|-----------|-----------|----------|----------|------|
| 0 | 1 | 10 | 0 | 5 | 小型木筏 |
| 1 | 2 | 20 | 5 | 10 | 中型帆船 |
| 2 | 3 | 50 | 20 | 30 | 大型船 |

4. **配置安全重生点**
   - 在场景中创建一个空对象作为重生点（如主岛码头）
   - 将该对象拖拽到 **Safe Respawn Point** 字段
   - **重要**：确保重生点不在海里，而是在陆地/码头上

5. **配置下船偏移**
   - **Leave Raft Offset**: 默认 2f
   - 下船时玩家距离船的距离

---

### 步骤2：创建VoyageInputHandler对象

1. **创建空对象**
   - Hierarchy → Create Empty
   - 重命名为 "VoyageInputHandler"

2. **添加组件**
   - Add Component → 搜索 `VoyageInputHandler`

3. **配置按键**（可选）
   - **Leave Raft Key**: 默认为 `F`
   - 如果需要修改，改为其他按键（如 `G`）

---

### 步骤3：配置voyagetrigger生成点

找到场景中的 `voyagetrigger` 对象（通常在海边/码头）：

1. **选择 voyagetrigger 对象**
   - 在Inspector中找到 **Voyage Trigger** 组件

2. **配置生成点数组**
   - 展开 **Spawn Points** 数组
   - 设置 **Size** ≥ 1（至少1个生成点）
   - 拖拽场景中的空对象作为生成点位置

3. **选择生成点索引**
   - **Selected Spawn Point Index**: 默认 0
   - 如果有多个生成点，可以选择使用哪一个

4. **确保UI引用**
   - **Goto Sea UI**: 拖拽场景中的 `GotoSeaCanva` 对象

---

### 步骤4：配置下船按钮（可选）

如果想要按钮下船功能：

1. **创建下船按钮**
   - 在 `ButtonCanvas` 下创建新的UI按钮
   - 重命名为 "LeaveRaftButton"
   - 设置按钮文本为 "下船"

2. **配置ButtonCanvaController**
   - 选择场景中的 `ButtonCanvas` 对象
   - 在Inspector中找到 **Button Canva Controller** 组件
   - 将 `LeaveRaftButton` 拖拽到 **Leave Raft Button** 字段

3. **触发显示下船按钮**
   - 当玩家进入岛屿范围时，调用：
     ```csharp
     ButtonCanvaController.Instance.ShowButton("leaveraft");
     ```
   - 这通常在 `PlayerLocationTrigger` 的 `OnTriggerEnter` 中处理

---

### 步骤5：配置PlayerLocationTrigger（重要）

确保所有岛屿都有 `PlayerLocationTrigger` 覆盖：

1. **为每个岛屿添加Trigger**
   - 创建空对象，添加 Box Collider
   - 勾选 **Is Trigger**
   - 调整 Collider 大小覆盖整个岛屿

2. **添加PlayerLocationTrigger组件**
   - Add Component → 搜索 `PlayerLocationTrigger`
   - 设置 **Location** 为对应的岛屿状态：
     - 主岛: `主岛`
     - 其他岛屿: `岛屿1`, `岛屿2` 等

3. **配置Tag**
   - 确保 Player 对象的 Tag 为 "Player"

## ⚠️ 常见问题

### 问题1：报错"无法获取选中的生成点"
**原因**：voyagetrigger 的 Spawn Points 数组为空

**解决方法**：
1. 找到场景中的 voyagetrigger 对象
2. 在 Inspector 中展开 Spawn Points 数组
3. 设置 Size ≥ 1
4. 拖拽空对象作为生成点位置

---

### 问题2：下船按钮不显示
**原因**：
- ButtonCanvaController 的 Leave Raft Button 字段未配置
- 或者没有调用 `ShowButton("leaveraft")`

**解决方法**：
1. 确保 ButtonCanvaController 的 Leave Raft Button 已配置
2. 在 PlayerLocationTrigger 或其他地方调用：
   ```csharp
   if (ButtonCanvaController.Instance != null)
   {
       ButtonCanvaController.Instance.ShowButton("leaveraft");
   }
   ```

---

### 问题3：船上退出后无法加载
**原因**：VoyageSystemManager 的安全重生点未配置

**解决方法**：
1. 选择 VoyageSystemManager 对象
2. 在 Inspector 中找到 Safe Respawn Point 字段
3. 拖拽场景中的重生点对象（如主岛码头）

---

### 问题4：资源不足但仍能生成船
**原因**：ResourceManager 不存在或未初始化

**解决方法**：
1. 检查场景中是否有 ResourceManager 对象
2. 确保ResourceManager 的 Awake 先于 VoyageSystemManager 执行
3. 可以在 Script Execution Order 中调整顺序

## 🎮 使用示例

### 在代码中调用航海系统

```csharp
// 检查玩家是否在船上
if (VoyageSystemManager.Instance != null && VoyageSystemManager.Instance.IsOnRaft)
{
    Debug.Log("玩家在船上");
}

// 检查是否可以下船
if (VoyageSystemManager.Instance != null && VoyageSystemManager.Instance.CanLeaveRaft())
{
    Debug.Log("可以下船");
}

// 获取船只类型
int shipType = VoyageSystemManager.Instance.CurrentShipType;

// 获取资源消耗配置
ShipResourceCost cost = VoyageSystemManager.Instance.GetShipCostPublic(1);
Debug.Log($"船类型1消耗: Crop={cost.cropCost}, Ani={cost.aniCost}, Mat={cost.matCost}");
```
