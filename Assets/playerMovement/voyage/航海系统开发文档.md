## 📋 核心脚本详解

### 1️⃣ VoyageSystemManager.cs

**📍 位置**: `Assets/playerMovement/voyage/VoyageSystemManager.cs`

**🎯 类型**: 单例管理器 (MonoBehaviour)

**💡 核心功能**:
- 统一管理航海系统的所有逻辑
- 船只生成和销毁
- 资源消耗检查和扣除
- 上船/下船状态管理
- 存档集成

**🔑 关键字段**:
```csharp
public static VoyageSystemManager Instance { get; private set; }

[SerializeField] private ShipResourceCost[] shipCosts;        // 船只资源消耗配置
[SerializeField] private Transform safeRespawnPoint;         // 安全重生点
[SerializeField] private float leaveRaftOffset = 2f;          // 下船偏移距离

private RaftController currentRaft;                         // 当前船只
private int currentShipType;                                // 当前船只类型
private bool isOnRaft;                                      // 是否在船上
```

**🔧 核心方法**:
| 方法 | 功能 | 被谁调用 |
|------|------|---------|
| `TrySpawnAndBoardRaft()` | 生成船并让玩家上船 | GotoSeaUIController |
| `LeaveRaft()` | 玩家下船 | VoyageInputHandler, PlayerController |
| `CanLeaveRaft()` | 检查是否可以下船 | VoyageInputHandler, PlayerController |
| `SetCurrentRaft()` | 设置当前船只 | 内部调用 |
| `ConsumeResources()` | 消耗资源 | 内部调用 |

**🔗 连接关系**:
```
VoyageSystemManager (单例)
    ↓ 被调用
    ├─→ GotoSeaUIController.OnShipSelected()
    │      └─→ TrySpawnAndBoardRaft()
    │
    ├─→ VoyageInputHandler.OnInteractionPerformed()
    │      └─→ LeaveRaft()
    │
    ├─→ PlayerController.HandleDismountInput()
    │      └─→ LeaveRaft()
    │
    └─→ PlayerStateManager (保存/加载时)
           └─→ GetSafeRespawnPoint()
```

### 3️⃣ VoyageInputHandler.cs

**📍 位置**: `Assets/playerMovement/voyage/VoyageInputHandler.cs`

**🎯 类型**: 输入处理器 (MonoBehaviour)

**⚠️ 状态**: **已弃用** (2026-01-26)

**💡 迁移说明**:
从 2026-01-26 版本开始，下船功能已完全迁移到 **PlayerController.HandleDismountInput()**。

**原因**:
- 简化输入处理逻辑，避免重复监听
- 统一在 PlayerController 中处理船只交互
- 使用 `IsPressed()` 替代回调，更易控制

**建议**: 请从场景中移除此组件。脚本保留仅为兼容性，实际功能已禁用。

**🔧 核心方法**:
| 方法 | 功能 | 被谁调用 |
|------|------|---------|
| `OnTriggerEnter()` | 玩家进入触发范围 | Unity Physics |
| `OnTriggerExit()` | 玩家离开触发范围 | Unity Physics |
| `Update()` | 检测F键输入 | Unity Update |
| `TryOpenShipSelectionUI()` | 打开选船UI | 内部调用 |
| `GetSelectedSpawnPoint()` | 获取选中的生成点 | GotoSeaUIController |

**🔗 连接关系**:
```
Unity Physics: Collider
    ↓ 触发
voyagetrigger.OnTriggerEnter(Collider other)
    ↓ 检查Tag == "Player"
    ├─→ buttonCanvaController.ShowButton("voyage")
    └─→ 设置 playerInRange = true

玩家按F键
    ↓
voyagetrigger.Update()
    ↓ 检测 Keyboard.current[F].wasPressedThisFrame
    ↓
TryOpenShipSelectionUI()
    ↓ 设置引用
gotoSeaUI.SetPlayerController(playerController)
gotoSeaUI.SetVoyageTrigger(this)
gotoSeaUI.SetSpawnPoint(GetSelectedSpawnPoint())
    ↓
gotoSeaUI.ShowCanvas()
```

**🎨 场景配置**:
- 在海岸线/码头位置创建 GameObject
- 添加 BoxCollider 或 SphereCollider
- 设置 `isTrigger = true`
- 配置 `spawnPoints` 数组（船只生成位置）

### 6️⃣ PlayerController.cs

**📍 位置**: `Assets/playerMovement/playerController.cs`

**🎯 类型**: 玩家控制器 (MonoBehaviour)

**💡 核心功能**:
- 玩家移动和跳跃

- 摄像机控制

**🔑 关键字段（船只相关）**:
```csharp
[Header("上船控制设置")]
public float onRaftCheckRadius = 5f;           // 检测半径
public float switchToRaftControlDelay = 2f;    // 切换到控制模式的延迟
public bool enableDebugLogs = true;            // 调试日志

[Header("船只交互设置")]
public Vector3 raftStandOffset = new Vector3(0f, 0.5f, 0f);

public float dismountUpOffset = 0.5f;

[Header("输入设置")]
private playerInputActions inputActions;
private InputAction interactionAction;

// 内部状态
private RaftController currentRaft;            // 当前所在的船
private float timeOnRaft;                      // 在船上的时间
private bool isControllingRaft;               // 是否正在控制船
private Transform originalParent;              // 原始父对象
```

**🔧 核心方法（船只相关）**:
| 方法 | 功能 | 被谁调用 |
|------|------|---------|
| `CheckIfOnRaft()` | 检测玩家是否在船上 | Update() 每帧调用 |
| `UpdateRaftControl()` | 更新船的控制状态 | Update() |
| `ControlRaftWithWASD()` | 使用WASD控制船 | 内部调用 |
| `AttachPlayerToRaft()` | 玩家绑定到船上 | 内部调用 |
| `DetachFromRaft()` | 玩家脱离船 | 内部调用 |
| `HandleDismountInput()` | 处理F键输入 | Interaction Action 回调 |
| `PerformDismount()` | 执行下船逻辑 | 内部调用 |
| `ForceBoardRaft()` | 强制上船（外部调用） | VoyageSystemManager |
| `ForceLeaveRaft()` | 强制下船（外部调用） | VoyageSystemManager |
| `IsOnRaft()` | 检查是否在船上 | 外部查询 |
| `IsControllingRaft()` | 检查是否在控制船 | 外部查询 |

**🔗 连接关系**:
```
【上船流程】
VoyageSystemManager.TrySpawnAndBoardRaft()
    ↓
PlayerController.ForceBoardRaft(raft)
    ↓
currentRaft = raft
isControllingRaft = true
AttachPlayerToRaft()
    ├─ 禁用 CharacterController
    ├─ 设置父对象为船
    ├─ 传送玩家到 standPoint
    └─ 设置摄像机

【控制船流程】
PlayerController.Update()
    ↓ 检测 currentRaft != null
UpdateRaftControl()
    ↓ 检测 isControllingRaft
ControlRaftWithWASD()
    ↓
RaftController.SetDirectControlDirection(moveDirection)

【下船流程】（2026-01-26 更新）
Input System: Interaction Action (F键)
    ↓
PlayerController.Update() 检测 IsPressed()
    ↓
HandleDismountInput()
    ├─ 未控制船 → AttachPlayerToRaft() (进入控制模式)
    └─ 已控制船
        ├─ 检查 VoyageSystemManager.CanLeaveRaft() (靠近岛屿)
        └─ 通过检查 → VoyageSystemManager.LeaveRaft()
```

### 8️⃣ PlayerStateManager.cs

**📍 位置**: `Assets/System/PlayerMode/PlayerStateManager.cs`

**🎯 类型**: 单例管理器 (MonoBehaviour)

**💡 核心功能**:
- 玩家状态保存和加载
- 位置状态管理（海上/岛屿）
- 队友数据保存

**🔑 关键字段**:
```csharp
public static PlayerStateManager Instance { get; private set; }

private PlayerController playerController;
private PersonManager personManager;
private PlayerLocationState currentLocation;
```

**🔧 核心方法**:
| 方法 | 功能 | 被谁调用 |
|------|------|---------|
| `SavePlayerState()` | 保存玩家状态 | GlobalSaveManager, VoyageSystemManager |
| `LoadPlayerState()` | 加载玩家状态 | GlobalSaveManager |

| `CurrentLocation` | 获取当前位置 | 外部查询 |

**🔗 连接关系**:
```
【保存流程】
GlobalSaveManager.SaveAllData()
    ↓
PlayerStateManager.SavePlayerState()
    ├─ 检查 playerController.IsOnRaft()
    │   ├─ 不在船 → 保存 position 和 rotation
    │   └─ 在船 → 保存 Vector3.zero (作为标记)
    └─ 保存 currentLocation

【加载流程】
GlobalSaveManager.LoadAllData()
    ↓
PlayerStateManager.LoadPlayerState()
    ├─ 恢复 currentLocation
    ├─ 恢复 playerPosition 和 rotation
    └─ 如果之前在船 → 传送到安全重生点
```

## 🐛 已知Bug

### 🔴 玩家下船后消失，重生在(0,0,0)

**问题**: 下船后没有立即保存玩家状态，导致游戏退出时保存了错误的位置。

**解决方案**: 在 `VoyageSystemManager.LeaveRaft()` 第187行后添加：

```csharp
// 立即保存玩家状态，确保下船位置被正确记录
if (PlayerStateManager.Instance != null)
{
    PlayerStateManager.Instance.SavePlayerState();
    if (showDebugLog) Debug.Log("[VoyageSystemManager] 已保存玩家下船后的状态");
}
```

**修改位置**: [Assets/playerMovement/voyage/VoyageSystemManager.cs:187](Assets/playerMovement/voyage/VoyageSystemManager.cs#L187)
