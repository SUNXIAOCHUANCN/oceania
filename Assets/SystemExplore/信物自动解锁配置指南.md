# 信物自动解锁系统 - 配置指南

## 🎯 新规则说明

**修改后的解锁规则：**

1. **与NPC对话** → 解锁**秘密**（Secret）
2. **岛屿100%完成** + **点击岛屿Page按钮** → 自动解锁**信物**（Token）

**岛屿100%完成的定义：**
- ✅ 所有物种（Species）已解锁
- ✅ 所有线索（Clues）已解锁
- ✅ 秘密已解锁
- ❌ **不包括**信物（信物需要点击按钮解锁）

## 💻 代码修改

### 已修改文件：IslandPageController.cs

**新增方法：**

```csharp
public void OnPageButtonClick()
{
    // 1. 刷新显示
    RefreshDisplay();

    // 2. 检查岛屿是否完成
    if (manager.IsIslandComplete() && !manager.IsTokenUnlocked())
    {
        // 3. 自动解锁信物
        manager.UnlockToken();
        DisplayToken(); // 立即刷新显示
    }
}
```

**工作流程：**
```
玩家点击岛屿Page按钮
    ↓
OnPageButtonClick() 被调用
    ↓
检查 IsIslandComplete()
    ├─ true → 检查 IsTokenUnlocked()
    │   ├─ false → 自动解锁信物 ✓
    │   └─ true → 提示"信物已解锁"
    └─ false → 提示"岛屿未完成，进度XX%"
```

## 🔧 Unity配置步骤

### 第1步：确认岛屿Page的UI结构

在Hierarchy中找到岛屿Page对象：

```
ExploreCanva
├─ MainIslandPage (GameObject)
│  ├─ IslandPageController (脚本)
│  └─ Button (或其他交互组件) ← 需要配置这个
│
└─ CrossIslandPage (GameObject)
   ├─ IslandPageController (脚本)
   └─ Button (或其他交互组件) ← 需要配置这个
```

### 第2步：配置Button的OnClick事件

以**MainIslandPage**为例：

1. 在Hierarchy中选中 `MainIslandPage`
2. 在Inspector中找到 **Button** 组件
3. 展开 `On Click()` 面板
4. 点击 `+` 添加事件
5. 将 `MainIslandPage` 对象**拖入**到Object槽
6. 下拉菜单选择：`IslandPageController → OnPageButtonClick`

**配置示例：**
```
Button:
└─ On Click():
   ├─ Size: 1
   └─ Element 0:
      ├─ Object: MainIslandPage  ← 拖入这个对象本身
      └─ Function: IslandPageController.OnPageButtonClick  ← 选择这个方法
```

### 第3步：为每个岛屿Page重复此操作

需要对每个岛屿Page都配置：

```
✓ MainIslandPage → Button → OnClick → OnPageButtonClick
✓ CrossIslandPage → Button → OnClick → OnPageButtonClick
✓ ...其他岛屿
```

## ⚠️ 注意事项

### 1. 每个岛屿Page都需要配置

确保每个岛屿Page的Button都配置了OnClick事件：

```
✓ MainIslandPage
✓ CrossIslandPage
✓ ...其他岛屿
```

### 2. UI结构可能不同

如果你的UI结构不是Button，而是其他交互方式（如Toggle、EventTrigger），需要相应调整：

**使用EventTrigger：**
```
MainIslandPage:
└─ Event Trigger
   ├─ Pointer Click
   │  └─ IslandPageController.OnPageButtonClick
```

**使用自定义脚本：**
```csharp
public class CustomIslandButton : MonoBehaviour, IPointerClickHandler
{
    private IslandPageController controller;

    void Awake()
    {
        controller = GetComponent<IslandPageController>();
    }

    public void OnPointerClick(PointerEventData eventData)
    {
        controller?.OnPageButtonClick();
    }
}
```

### 3. 避免重复触发

代码已经处理了重复解锁的情况，不会重复触发：

```csharp
if (!manager.IsTokenUnlocked())  // 检查是否已解锁
{
    manager.UnlockToken();
}
```

## 🐛 常见问题

### 问题1：点击按钮没反应

**检查：**
- Button的OnClick事件是否已配置？
- Object是否是正确的岛屿Page对象？
- Function是否选择了OnPageButtonClick？

### 问题2：点击后没解锁信物

**检查：**
- Console是否显示"岛屿未完成"？
  → 是：继续探索岛屿
- Console是否显示"信物已解锁"？
  → 是：信物已经解锁过了
- Console是否完全没有日志？
  → 检查IslandPageController脚本是否正确附加

### 问题3：解锁后UI不更新

**解决：** 代码已经包含自动刷新：
```csharp
manager.UnlockToken();
DisplayToken(); // 立即刷新显示
```

如果还是不更新，检查：
- TokenDisplayItem的UpdateDisplay方法是否正确？
- 是否需要手动调用RefreshDisplay()？
