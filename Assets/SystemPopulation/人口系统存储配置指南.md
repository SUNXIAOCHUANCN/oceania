## 🎮 Hierarchy 布置说明

### 在场景中添加 GameObject

1. **打开主场景** `MainIsland.unity` 或持久化管理器场景

2. **创建 GameObject**（如果没有）：
   ```
   Managers (空 GameObject，用于组织)
   ├── GlobalSaveManager
   ├── PersonSaveSystem ⭐ (新增)
   └── PersonManager
   ```

3. **添加组件**：
   - 选中 `PersonSaveSystem` GameObject
   - Add Component → 搜索 `PersonSaveSystem`
   - 它会自动设置为 DontDestroyOnLoad

4. **配置 GlobalSaveManager**：

   选中 `GlobalSaveManager` GameObject，在 Inspector 中确保：

   ```
   GlobalSaveManager (Script)

   [系统引用]
   ☑ Global Time System
   ☑ Player State Manager
   ☑ Forest Save System
   ☑ Farm Save System
   ☑ Ranch Save System
   ☑ Explore Save System
   ☑ Person Save System    ⭐ 拖入 PersonSaveSystem GameObject

   [人口系统引用]
   ☑ Person Manager        ⭐ 拖入 PersonManager GameObject
   ```

## 📊 存档数据格式

存档文件位置：
- **Windows**: `%AppData%\..\LocalLow\[公司名]\[项目名]\population_save.dat`
- **macOS**: `~/Library/Application Support/[公司名]/[项目名]/population_save.dat`

**JSON 格式示例**：
```json
{
  "personsData": [
    {
      "personName": "Lifa",
      "isRecruited": true,
      "statusName": "rest"
    },
    {
      "personName": "Soda",
      "isRecruited": false,
      "statusName": "rest"
    }
  ],
  "saveVersion": 1
}
```

## ❗ 重要提示

### 关于 ScriptableObject 消耗值的修改

**Q: 如果我修改 PersonScriptableObject 的 monthlyCropConsumption，会有冲突吗？**

**A: 不会冲突**。设计原则如下：

| 数据类型 | 存储位置 | 示例 | 是否持久化 |
|---------|---------|------|----------|
| **设计时数据** | ScriptableObject | 消耗值、职业描述 | 否（运行时不修改）|
| **运行时状态** | 存档系统 | recruited、status | 是（保存到文件）|

**修改消耗值的效果**：
- ✅ 新游戏会使用新的消耗值
- ✅ 旧存档也会使用新消耗值（因为存档不保存消耗值）
- ✅ 这是**期望的行为**（平衡性调整应该影响所有游戏）

**如果想要旧存档使用旧消耗值**：
- 需要在存档中保存消耗值
- 但这通常**不推荐**（会导致平衡性调整无法影响旧存档）

## 🐛 常见问题

### 问题 1：找不到 PersonSaveSystem.Instance

**原因**：场景中没有 `PersonSaveSystem` GameObject

**解决**：
1. 在 Hierarchy 中创建 GameObject
2. 添加 `PersonSaveSystem` 组件

### 问题 2：人员加载时显示"未找到人员 XXX"

**原因**：存档中的人员名称与 ScriptableObject 中的名称不匹配

**解决**：
- 确保所有 `PersonScriptableObject` 的 `personName` 字段唯一且不为空
- 不要在创建存档后修改人员名称

### 问题 3：招募状态没有保存

**原因**：可能使用了旧版本的代码

**解决**：
- 确保已移除 `SaveToPlayerPrefs()` 和 `LoadFromPlayerPrefs()` 的调用
- 确保使用的是新的 `ExportToSaveData()` 和 `LoadFromSaveData()` 方法
